# Synergy

This is a school project for developing a front-end for an e-commerce website.  Synergy is just the project's name.

## Setup

First install node and npm into your system.
Then clone the project using this command:

    git clone https://github.com/varus860/Synergy.git
After cloning the project, install the dependencies:

    npm install

Start the local sever using:

    npm run dev
